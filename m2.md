1.  它接收一个初始节点 `initNode` (通常应该是 `document.body` 或 `document.documentElement`)。
2.  它使用一个内部的深度优先搜索（DFS）函数 `dfs` 来遍历 DOM 树。
3.  在 `dfs` 函数中，对于每个遍历到的 DOM 节点 (`node`):
    *   它会调用 `collectElementInfo(node, ...)` 来尝试提取该节点的信息。
    *   如果 `collectElementInfo` 返回了有效的 `elementInfo`，则将其作为当前树节点的 `node` 字段。
    *   如果 `collectElementInfo` 返回 `null`（表示该节点不被认为是一个需要提取的元素），则当前树节点的 `node` 字段会被设为 `null`。
    *   然后递归地处理子节点。

**`collectElementInfo` 函数的逻辑概要：**

这个函数负责判断一个 DOM 节点是否是 "有意义的" 元素，并提取其信息。它包含很多条件和启发式规则：

1.  **获取矩形 (Rect)**：首先调用 `elementRect` 获取元素的边界框。如果获取不到（例如元素不可见或无尺寸），则返回 `null`。
2.  **最小尺寸过滤**：如果 `visibleOnly` 为 true（默认），且元素宽度小于 `CONTAINER_MINI_WIDTH` (1) 或高度小于 `CONTAINER_MINI_HEIGHT` (1)，则返回 `null`。
3.  **全视口元素过滤**：如果元素的矩形占据了整个视口 (`rect.height >= window.innerHeight && rect.width >= window.innerWidth`)，它会返回 `null`。**这是一个非常关键的过滤条件，因为 `<html>` 和 `<body>` 元素通常会满足这个条件！**
4.  **类型判断**：然后它会根据 `isFormElement`, `isButtonElement`, `isImgElement`, `isTextElement`, `isContainerElement` 等函数来判断元素的类型，并据此提取不同的属性和内容。
5.  如果所有类型都不匹配，或者不满足特定类型的条件（例如文本元素没有文本内容），它也可能返回 `null`。

  initNode: globalThis.Node,
  debugMode = false,

  const topDocument = getTopDocument(initNode.ownerDocument || document);

  let extractedRootNode = dfs( // dfs 的结果可能是 { node: ElementInfo | null, children: [...] } 或 null
    initNode,
    topWindow,
    topDocument,

    // 尝试为 initNode 创建一个兜底的 ElementInfo，主要用于根节点场景
    const rect = elementRect(initNode, topWindow, topDocument, 1, false); // visibleOnly = false for root

          id: nodeHashId,
          nodeHashId,
          locator: '', // Root node might not have a simple selector
          nodeType: NodeType.CONTAINER, // Treat root as a container
          indexId: indexId++,
          attributes: {
            ...attributes,

            nodeType: NodeType.CONTAINER,
          },
          content: '',

          zoom: rect.zoom,

      const nodeHashId = midsceneGenerateHash(initNode, 'document_root', rect);
      extractedRootNode.node = { // 修改 node 字段

  currentBaseZoom = 1,

    currentNode,
    currentWindow,
    currentDocument,
    currentBaseZoom,
    currentBasePoint,
